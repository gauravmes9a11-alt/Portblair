# Gaurav Shivakumar - Personal Portfolio & Interactive Showcase


## 🚀 Overview

An interactive, high-performance web portfolio featuring:
- **Interactive Pareto Front Visualizer**: Live trade-off exploration tool demonstrating multi-objective optimization (fuel burn vs. endurance) with hover tooltips.
- **Dedicated Project Windows (Modals)**: In-depth technical architecture breakdowns, hardware schematics, and performance metrics for:
  - **AeroPulse** (HAL × IIT Indore Aerothon 2026 Winner)
  - **HP ONE** (HPCL Summer Internship 2026)
  - **PEIRL** (ISRO Bharatiya Antariksh Hackathon 2026)
  - **PIDS** (Pipeline Intrusion Detection System)
  - **SVD Steganography**, **FIFA Predictor**, **Drowsiness Detection**, **Real-Time Quiz**, and **Flight Management**.
- **Smooth Animations & Micro-Interactions**:
  - Top scroll reading progress bar.
  - Floating back-to-top button with circular SVG progress ring.
  - Ambient spotlight card cursor tracking.
  - Staggered scroll entrance reveals.
  - Smooth details expansion and metric count-up animations.
- **Accessibility & Performance**:
  - Full `@media (prefers-reduced-motion: reduce)` support.
  - Native semantic HTML, responsive layout, zero heavy dependencies.

## 🛠️ Stack

- Pure Modern HTML5, CSS3, Vanilla JavaScript (ES6+)
- Vector SVG System Architecture Diagrams
- Schibsted Grotesk Typography
